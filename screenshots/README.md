# imgwand screenshots

Generated by `scripts/screenshots/run.ts` from the standalone binary running in tmux (150×40), and directly in a pseudo-terminal for inline images, rendered with xterm.js and its image addon.

## 1. Browser

imgwand opens on a folder: subfolders and supported images (JPEG, PNG, WebP), k9s-style header with context and key hints.

![Browser](01-browser.png)

## 2. Filtering

/ filters the list as you type.

![Filtering](02-browser-filter.png)

## 3. Metadata inspector

sunset.jpg: every field grouped (C2PA, EXIF, GPS, thumbnail, XMP, IPTC, Photoshop, ICC, comments), identifying fields flagged with •, a live preview (colored blocks inside tmux; real pictures directly in a terminal, see below) and field details on the right.

![Metadata inspector](03-inspector.png)

## 4. Filtered to GPS

Filtering by 'gps' finds the EXIF GPS IFD and the XMP GPS property; values are decoded (degrees, minutes, seconds and decimal).

![Filtered to GPS](04-inspector-gps.png)

## 5. Content Credentials

c opens the C2PA view: validation state, signer, actions and assertions of the signed manifest, validated with the official C2PA SDK.

![Content Credentials](05-c2pa.png)

## 6. Redacting an assertion

r prompts for an assertion to redact, suggesting the ones that can be redacted.

![Redacting an assertion](06-c2pa-redact-prompt.png)

## 7. Redacted and re-signed

The new active manifest records the redaction and keeps the original manifest as its parent ingredient; the redacted assertion is gone from it.

![Redacted and re-signed](07-c2pa-redacted.png)

## 8. Writing the new signature

w shows exactly what will be written before anything touches the disk.

![Writing the new signature](08-write-signature.png)

## 9. Marking fields

space marks fields (●); a marks a whole group.

![Marking fields](09-marked.png)

## 10. Staged removals

d stages the marked fields for removal (✗, struck through). Nothing is written yet; u undoes.

![Staged removals](10-staged.png)

## 11. Editing a value

e edits the selected field in place.

![Editing a value](11-edit.png)

## 12. Staged edit

The new value is staged (~) next to the old one.

![Staged edit](12-edit-staged.png)

## 13. Command line

The : command line takes selectors: groups, ids, globs and presets.

![Command line](13-command.png)

## 14. Privacy preset

P stages the privacy preset: location, names, serial numbers, comments, document IDs and thumbnails. Camera settings, the ICC profile and C2PA stay.

![Privacy preset](14-privacy.png)

## 15. Writing a signed file

The file is signed, so removing anything invalidates its Content Credentials: imgwand asks whether to remove them too or keep the invalid manifest.

![Writing a signed file](15-write-c2pa-choice.png)

## 16. Written

Written atomically; the compressed picture is byte-identical (verified before writing). The remaining fields are what the photo still says about itself.

![Written](16-written.png)

## 17. Help

? lists every key and command.

![Help](17-help.png)

## 18. Full-screen preview

p previews full screen with the best protocol the terminal supports (here colored half blocks inside tmux; see the sixel and iTerm2 renders below).

![Full-screen preview](18-preview-fullscreen.png)

## 19. Graphics fallback

g cycles through the available renderers.

![Graphics fallback](19-preview-ascii.png)

## 20. Unsaved changes

Quitting or leaving with staged edits asks first.
